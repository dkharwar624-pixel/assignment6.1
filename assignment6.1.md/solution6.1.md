I created a webpage containing three different cards or boxes, each with a heading and a paragraph. The main objective was to understand and inspect the CSS Box Model which consists of four parts: content, padding, border, and margin. For Box 1, I applied box-sizing: content-box which is the default behavior, with padding of 20px, border of 5px solid blue, and margin of 20px. In this model, the width of 300px applies only to the content area, so the padding and border are added extra, making the total rendered width 350px. For Box 2, I used box-sizing: border-box with the same padding, border, and margin values but with a green border. Here the width of 300px includes the padding and border inside it, so the content area automatically shrinks to adjust, which keeps the total size fixed at 300px and is more suitable for responsive layouts. For Box 3, I also used border-box but with larger values to make the layers more visible, with padding of 40px, border of 15px dashed orange, and margin of 40px. When inspected in Chrome DevTools by right-clicking and selecting Inspect and then going to the Computed tab, the box model diagram clearly shows the content in the center, padding around it in green, border around padding in yellow/blue, and margin as the outermost orange area. This inspection helped me observe that content-box increases the element size unexpectedly while border-box provides predictable sizing, which is why modern web design prefers border-box for better layout control.
